# Trading Terminal Starter

Create a minimal Vite + React + TypeScript + Tailwind app with one blank page titled "Trading Terminal".

No extra features, no auth, no database, no sample content. The real codebase will be pushed via GitHub sync.

This project was built with [Lovable](https://lovable.dev).
