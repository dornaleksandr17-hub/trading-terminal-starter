# CHANGES_APPLIED_TWEEZER_HTF_DIAGNOSTICS_20260929.md — измерение потолка confidence: tweezer, HTF-множитель, hammer-семейство

Дата: 2026-09-29. Поведение детекторов и вердикты аудита НЕ менялись — только измерение.

## Симптом

Реальный прогон `horizon-audit` (EURUSD/GBPUSD/USDJPY/AUDUSD, 1m, 2026-03-01..2026-09-17,
195841 свеча/символ, 781244 оценённых бара, 203347 occurrences) показал шесть паттернов
с 0 срабатываний (`mean-reversion`, `tweezer-bottom/top`, `abandoned-baby-bottom/top`,
`falling-three-methods`). Воронка гейтов `--funnel` показала, что у tweezer нет проблемы
подключения (`00-evaluated = 781244`), но кандидаты, прошедшие `06-confirmation`
(32155 у bottom, 32764 у top), ни разу не проходят confidence >= 0.5. Воронка не
различала, ЧТО именно душит confidence.

## Причина (по данным диагностических счётчиков)

1. **`volume ≡ 0` у Deriv** (`deriv.ts:243,473`, `data-loader.ts:444`): `tweezerVolumeFactor`
   всегда возвращает 0.90 (`volume-none = 100%`). Контрфактический замер (confidence с
   нейтральным объёмом) показал: **0 из 32155 / 0 из 32764 прошли бы и без объёмного
   штрафа**. Объём НЕ определяющий фактор; правка по образцу `hasReliableVolume`
   (engulfing, 2026-09-20) для tweezer ничего бы не дала и не вносилась.
2. **Потолок формулы.** `0.40 × htf × session × volume × confirm × rsi >= 0.5`.
   Распределение HTF-класса среди кандидатов tweezer-bottom: 1.00-bos 12 (0.04%),
   0.75-choch 564 (1.8%), 0.5 21161 (65.8%), 0.4 10418 (32.4%). 98.2% кандидатов
   (классы 0.5 и 0.4) не достигают 0.5 ни при какой комбинации прочих множителей.
   Типичная confidence лежит в корзинах 0.1–0.2 (98.5% кандидатов). Все BOS-кандидаты
   (12 / 5) имеют RSI в зоне множителя 0.85, совместный срез BOS × RSI ≤ 35 пуст.
3. **Гейт `01-twin-extreme` не фильтрует:** его проходят 99.92% (bottom) и 99.93% (top)
   баров. Допуск `0.001 × цена` ≈ 11 пипсов на EURUSD при диапазоне M1-свечи 1–3 пипса.
4. **HTF-множитель `htfAlignment` почти не несёт направленной информации.**
   По ВСЕМ барам (781244): класс 1.00-bos на 1.27% баров на сторону (buy 9937, sell 9959),
   0.75-choch на 2.21%, 0.5 на 62.8%, 0.4 (range) на 33.7%. `bos`/`choch` в
   `computeStructure` — пересечение уровня на последнем provisional M15-баре
   (`trend-structure.ts:57-62`), т.е. событие, а не состояние. Ветка «прочее» (0.5)
   не различает M15-тренд за сделку и против неё; `choch` даёт 0.75 без проверки
   направления. Среди кандидатов BOS-класс в 30–80 раз реже базовой частоты
   (tweezer-bottom 12 при ожидаемых ≈409, tweezer-top 5 при ≈418, hammer-семейство
   0 при ≈38) — разворотные паттерны по природе редко совпадают с M15 BOS в свою сторону.
5. **Hammer-семейство:** 2994 кандидата у confidence-гейта, 35 прошли (1.2%); BOS-класс
   0. По формуле shooting-star (`base × ha × … + obBonus`, порог 0.45, потолок base 0.45)
   без аддитивного `obBonus` классы 0.5/0.4 порог не достигают; 28 из 35 прошедших
   лежат именно в этих классах (вывод по формуле; остальные три детектора зеркальны по
   комментариям в коде, формулы целиком не сверялись).
6. **Прочие нулевые паттерны** (справочно): `mean-reversion` — 27 из 6052 «выход за BB и
   возврат» проходят RSI(7), все 27 не проходят confidence (base 0.1–0.4); RSI берётся на
   баре возврата. `abandoned-baby` — 99.4% отсева на `04-gaps-and-candle-c` (гэпов на
   непрерывном форексе M1 почти нет). `falling-three-methods` — 99.8% на `04-consolidation`.

## Что изменено

- `src/compute/patterns/double.ts` (+74 строки): в `detectTweezerBottom/Top` перед гейтом
  confidence — счётчики `diagCount` (HTF-класс, RSI-корзина, совместный срез, сила
  подтверждения, наличие объёма, корзина confidence, контрфактика с нейтральным объёмом).
  Работают только при активной диагностической трассировке (`--funnel`).
- `src/compute/patterns/index.ts` (+20 строк): в `detectAllPatterns` после `htfStructure`
  — счётчики `htf-baseline:*` на каждом баре (класс множителя для buy/sell, тренд, флаги
  bos/choch).
- Логика детекторов, пороги, базы, множители, `htfAlignment` — без изменений.

## Тесты

- `src/compute/patterns/tweezer-confidence-diag.test.ts` (7): счётчики при `volume ≡ 0`
  и при реальном объёме, срезы RSI/HTF, результат детектора идентичен с трассировкой и
  без, вне трассировки счётчики не копятся. На старом `double.ts` падают 5 из 7 (два
  инварианта проходят, как и должны).
- `src/compute/patterns/htf-baseline-diag.test.ts` (5): классы множителя по override-структуре,
  по одному классу на сторону на вызов, результат `detectAllPatterns` не меняется. На
  старом `index.ts` падают 3 из 5.
- Проверка «поведение не изменилось» на реальных данных: occurrences (203347; 51079 /
  50013 / 52523 / 49732) и сводка вердиктов (valid 0, rejected 3, insufficient 21)
  идентичны прогону до патча.
- `typecheck`, `lint` чистые. Замечание не по теме: `src/data/connection-manager.test.ts`
  использует реальные `sleep` (≈6.7 с в изоляции, таймаут 15 с) и один раз упал под
  нагрузкой полного набора; в изоляции зелёный.

## Что намеренно НЕ сделано

- Пороги, базы и множители не менялись: правка под желаемое число сигналов — подгонка
  (ключевое правило проекта). Гейт `twin-extreme` вырожден, поэтому смягчение confidence
  дало бы ≈64 тыс. сигналов шаблона «бычья свеча после медвежьих + подтверждение», а не пинцета.
- Аудит только форекс на Deriv; крипта (Binance, реальный объём) не измерялась.
